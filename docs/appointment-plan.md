# Appointment Plan

## Overview

The Appointment page allows clinic staff to create, manage, and monitor patient appointments.

---

## Purpose

This page displays all appointments in the clinic.

Users can:

- Create appointments
- Update appointments
- Cancel appointments
- Monitor appointment status

---

## Table Columns

- Patient Name
- Doctor
- Date
- Time
- Treatment
- Status
- Actions

---

## Appointment Status

Available appointment statuses:

- Waiting
- Confirmed
- Completed
- Cancelled
- No Show

---

## Features

- Search Appointment
- Filter by Doctor
- Filter by Date
- Pagination
- Add Appointment Modal
