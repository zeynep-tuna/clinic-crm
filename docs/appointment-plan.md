# Appointment List

## Purpose

This page displays all appointments in the clinic.

Users can create, update, cancel and monitor appointments.

---

## Table Columns

- Patient Name
- Doctor
- Date
- Time
- Treatment
- Status
- Actions

---

## Appointment Status

- Waiting
- Completed
- Cancelled
- No Show

---
