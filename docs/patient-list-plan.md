# Patient List

## Purpose

This page displays all registered patients in the clinic.
Users can search, filter, view, edit and delete patient records.

---

## Table Columns

- Full Name
- Phone
- Email
- Birth Date
- Doctor
- Last Appointment
- Status
- Actions

---

## Patient Status

- Active
- Passive
- New Patient
- Waiting for Control

---

## Future Features

- Search by patient name
- Filter by doctor
- Filter by status
- Export patient list
- Pagination
