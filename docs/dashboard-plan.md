# Dashboard Plan

## Overview

The Dashboard provides a quick overview of the clinic's daily activities and key statistics. It helps users monitor patients, appointments, doctors, and payment information from a single page.

---

## Dashboard Cards

Display the following summary cards:

- Total Patients
- Today's Appointments
- Active Doctors
- Pending Payments

---

## Recent Patients

Display the last 5 registered patients.

Information to show:

- Patient Name
- Phone Number
- Registration Date

---

## Today's Appointments

Display today's appointment list.

Information to show:

- Patient Name
- Doctor
- Department
- Appointment Time
- Status

---

## Payment Summary

Display payment statistics.

Information to show:

- Paid
- Pending
- Overdue
