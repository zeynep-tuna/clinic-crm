# Doctor Entity

Bu dosya ClinicCRM projesindeki Doctor (Doktor) modülünde kullanılacak veri alanlarını tanımlar.

| Alan | Veri Tipi | Açıklama |
|------|-----------|----------|
| DoctorId | int | Doktor kimliği |
| FullName | string | Doktorun adı ve soyadı |
| Specialty | string | Uzmanlık alanı |
| Phone | string | Telefon numarası |
| Email | string | E-posta adresi |
| Status | string | Aktif, Pasif veya İzinli |
| TodayAppointmentCount | int | Bugünkü randevu sayısı |
| CreatedAt | datetime | Kayıt oluşturulma tarihi |
