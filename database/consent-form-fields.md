# Consent Form Entity

This document defines the data fields used in the Consent Forms module.

| Field | Data Type | Description |
|--------|-----------|-------------|
| ConsentFormId | int | Consent form identifier |
| PatientName | string | Patient's full name |
| FormTitle | string | Title of the consent form |
| FormType | string | Type of the consent form |
| SignedDate | datetime | Date when the form was signed |
| Status | string | Current form status |
| FileUrl | string | File location of the signed document |
